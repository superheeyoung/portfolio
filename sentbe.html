센트비(2019.07~2022.03)

앱 링크(https://play.google.com/store/search?q=센트비&c=apps&hl=ko)

사용 기술

  • Kotlin
  • MVVM + Clean Architecture
  • ViewBinding
  • AAC
    • ViewModel
    • LiveData
    • Lifecycle
    • Room
  • Retrofit
  • RxJava
  • Koin

개발 내용

  • 앱 최초 런칭 후 안정화 작업을 수행하고, 50만 다운로드 규모의 앱을 확장·유지보수
    • 첫 배포 후 안정화 작업으로 크래시가 발생하지 않는 사용자 비율(crash-free) 99.7% 달성
  • 송금 시 수취인 정보 입력 화면에 SDUI 적용
    • 송금 국가·업체마다 입력받아야 하는 정보가 달라, 확장성을 위해 SDUI로 구현
  • 화면잠금번호 구현
    • 자동 로그인 세팅 로직
      로그인 성공 + 캐싱된 암호화 데이터 없음
      서버에서 PublicKey 받아오기
      ID, PW를 PublicKey로 RSA 암호화
      입력받은 화면잠금번호로 SHA256을 통해 Hash 생성
      AES256으로 한 번 더 암호화 (RSA로 암호화한 ID, PW를 앞서 생성한 Hash를 secret으로 사용해 AES256으로 한 번 더 암호화)
      AES256으로 암호화된 값 캐싱
    • 자동 로그인 처리 로직
      1. 저장된 AES256 값 확인 디바이스에 값이 있으면 진행
      2. 잠금번호로 SHA256 Hash 생성 사용자가 입력한 잠금번호
      3. AES256으로 저장된 ID, PW 값을 2번에서 생성한 Hash로 복호화
      4. 서버로 전송 후 로그인 처리 복호화가 올바르게 된 경우
  • 신규 기능 개발 및 메인 기능 UI 디자인 개편
