핵심 프로젝트

  • 미국 앱 수취인 정보 입력 화면을 SDUI 구조로 개선
    • 나라별 수취인 입력 항목을 앱 코드에서 직접 정의하던 방식을, 서버 응답으로 화면을 구성하는 SDUI로 전환
    • 송금 보내는 국가별로 수취 수단이나 받아야 하는 정보 변경이 자주 일어나, 변경될 때마다 앱을 배포할 수 없어 SDUI 구조로 수정
  • 오픈뱅킹 기능 출시 전 금융보안원 핀테크 서비스 취약점 점검 대응
    • 점검 결과, 신분증 인증 시 생년월일이 메모리 덤프에 평문으로 노출된다는 지적을 받음
    • Memory Profiler의 Heap Dump로 생년월일이 평문으로 남아 있는 것을 직접 확인
    • 생년월일을 다루는 구간을 모두 암호화하고, 값은 String 대신 CharArray로 다뤄 서버 통신 직후 메모리에서 즉시 삭제(wipe)하도록 수정
    • 수정 후 Heap Dump를 다시 확인해 평문이 남지 않음을 검증
  • 월렛 충전 금액 입력 화면을 Compose·MVI로 구현
    • 입금 방식과 입력 자릿수에 따라 입력값을 자동 환산해 표시하고, 환산 후에도 커서 위치가 유지되도록 구현
      • 은행계좌 입금 시: 1자리 입력은 ×1,000원, 2자리 이상은 ×100원으로 환산 (예: 1 → 1,000원, 125 → 12,500원)
    • 입력값이 바뀔 때마다 서버 데이터를 기준으로 검증(Validation)하고, 오류 시 안내 문구를 즉시 노출

그 외 업무

  • XML·DataBinding·MVVM 기반 화면과 디자인 시스템 커스텀 View를 Compose·MVI로 전환 (60% 전환)
  • 오픈뱅킹 거래내역 조회에 Paging 3를 적용해 무한 스크롤 구현
  • fastlane으로 Play 스토어·Firebase App Distribution 배포 자동화 및 배포 시간 단축
  • 코드 리뷰 시 Codex·Claude Code로 보조 검증
  • 앱 크래시 원인 분석 및 개선
